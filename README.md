# ReggaLink V3 - Phone to PC Screen Mirroring

By ReggadiO

The easiest way to mirror and control your Android phone from your PC. Lightweight, fast and no ads. A simple alternative to Scrcpy.

## Features

- High quality screen mirroring with low latency
- Full control from PC using mouse and keyboard
- Drag and drop file transfer
- One click screen recording and screenshots
- Works via USB cable and Wireless (WiFi)
- No root required
- Portable, no installation needed

## Download

1. Go to Actions tab
2. Open the latest workflow run
3. Download ReggaLink-V3-EXE.zip from Artifacts
4. Extract the zip
5. Run ReggaLink_V3.exe

You can also check the Releases section for stable builds.

## How to Use

1. Enable Developer Options on your phone:
   Settings > About Phone > Tap Build Number 7 times

2. Enable USB Debugging:
   Settings > Developer Options > USB Debugging

3. Connect your phone to your PC via USB

4. Run ReggaLink_V3.exe and click Connect

5. Accept the USB Debugging permission on your phone

## Requirements

- Windows 10 / 11
- Android 5.0 and above
- USB Cable

## Tech Stack

- Python
- ADB
